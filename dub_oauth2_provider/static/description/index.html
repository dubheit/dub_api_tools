Why this module

A standards-first authorization server inside Odoo

Odoo ships with an OAuth client, but no way to act as a server. This module fills that gap with a modern, audit-friendly, production-ready implementation.

It is the authentication backbone of the Dubhe MCP Server module, but it stands on its own and can protect any custom controller, REST endpoint or FastAPI route.

What's inside

Everything you need, nothing you don't

Authorization Code + PKCE

Safe for mobile, SPA and desktop clients. Challenge is enforced for public clients.

Client Credentials

Machine-to-machine authentication for services and background jobs.

Refresh Token Rotation

Long-lived sessions with minimal replay risk. Rotation is automatic.

OpenID Connect

Full /userinfo with openid, profile and email claims.

Discovery Endpoints

OAuth and OIDC metadata plus protected-resource discovery (RFC 9728).

Dynamic Client Registration

Personal Tokens

Every user can self-serve OAuth2 credentials from their preferences.

Token Revocation

RFC 7009 compliant /revoke endpoint and admin revoke UI.

Per-client Configuration

Allowed grants, scopes, redirect URIs and token TTL per OAuth2 client.

Supported flows

One module, three grant types

Every common OAuth2 scenario covered out of the box.

Authorization Code + PKCE

The recommended flow for any user-facing application. PKCE is mandatory for public clients.

Client Credentials

No human involved. The token is bound to the OAuth2 client for service-to-service calls.

Refresh Token

Extend access without re-prompting the user. Rotation is supported and recommended.

Built for production

Security by default

Hashed tokens at rest

Access tokens, refresh tokens and authorization codes are hashed before being stored.

Hashed client secrets

Secrets use PBKDF2 on creation. The plain value is shown only once.

Explicit consent

Every authorization code grant is approved by the user on a branded consent screen.

Auto-expiry & cleanup

Cron jobs clear expired tokens and codes. Retention is configurable per client.
