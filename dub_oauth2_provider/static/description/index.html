Turn your Odoo instance into an OAuth2 Authorization Server.

Key Features

Authorization Code Flow
Full OAuth2 Authorization Code grant type for server-side applications.

PKCE Support (S256)
Proof Key for Code Exchange for mobile apps and SPAs.

Client Credentials Flow
Machine-to-machine authentication without user interaction.

Personal Credentials
Users can create OAuth2 credentials from Preferences.

Refresh Token Rotation
Automatic token refresh with configurable expiration.

Configurable Expiration
Set access and refresh token lifetimes per client.

OAuth2 Endpoints

Endpoint Description
/oauth2/authorize Authorization endpoint - redirects user to login and consent
/oauth2/token Token endpoint - exchange code for access token
/oauth2/userinfo UserInfo endpoint - get authenticated user information
/oauth2/revoke Token revocation endpoint
/.well-known/oauth-authorization-server Server metadata (RFC 8414)
/.well-known/openid-configuration OpenID Connect discovery

Supported Scopes

openid

Verify user identity

profile

Access user profile (name, username)

email

Access user email address

Quick Setup

1. Go to Settings > Technical > OAuth2 Provider > Clients

2. Create a new OAuth2 Client with a name and redirect URI

3. Copy the Client ID and Client Secret

4. Configure your external application with these credentials

5. Users can now authenticate via /oauth2/authorize

Use Case: AI Assistant Integration

This module works with dub_mcp_server to enable AI assistants (Claude, Cursor, Continue, etc.) to securely access your Odoo data.
